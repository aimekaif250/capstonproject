# 🚨 PYTHON INSTALLATION REQUIRED

## Your system doesn't have Python installed!

To run the Cancer Risk Prediction System, you need Python 3.7 or higher.

---

## 📥 OPTION 1: Install from Microsoft Store (Easiest)

1. **Open Microsoft Store**
2. **Search for "Python"**
3. **Install the latest Python version** (Python 3.11 or 3.12 recommended)
4. **Wait for installation to complete**

---

## 📥 OPTION 2: Download from Python.org (Recommended for development)

1. **Open your browser**
2. **Go to: https://www.python.org/downloads/**
3. **Click "Download Python 3.12.0"** (or latest version)
4. **Run the installer**
5. **IMPORTANT: Check "Add Python to PATH"** during installation
6. **Click "Install Now"**

---

## ✅ VERIFICATION STEPS

After installation, open Command Prompt and run:

```cmd
python --version
```

You should see something like:
```
Python 3.12.0
```

---

## 🚀 NEXT STEPS (After Python Installation)

1. **Close and reopen Command Prompt**
2. **Navigate to your project:**
   ```cmd
   cd "d:\capstone project\code edition\cancer system"
   ```

3. **Run the setup script:**
   ```cmd
   setup.bat
   ```

4. **Run the application:**
   ```cmd
   run.bat
   ```

5. **Open in browser:**
   ```
   http://localhost:5000
   ```

---

## ❓ STILL HAVING ISSUES?

If you get errors after installation:

### Issue: "python is not recognized"
**Fix:** Make sure you checked "Add Python to PATH" during installation

### Issue: "Access denied" or "Permission denied"
**Fix:** Run Command Prompt as Administrator (right-click → Run as administrator)

### Issue: Old Python version
**Fix:** Download and install Python 3.7+ from python.org
