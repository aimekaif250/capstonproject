## 🚀 TO RUN THE APP

```bash
# Navigate to project folder
cd d:\capstone project\code edition\cancer system

# Activate virtual environment (Windows)
venv\Scripts\activate

# Install dependencies (first time only)
pip install -r requirements.txt

# Run the application
python app.py

# Open in browser
http://localhost:5000
```

| Method | URL | Purpose |
|--------|-----|---------|
| GET | `/` | Home page |
| GET | `/breast` | Breast form |
| GET | `/cervical` | Cervical form |

| POST | `/predict/cervical` | Cervical prediction |

## 📊 INPUT FEATURES

### Breast Cancer (6 fields)
- radius_mean
- texture_mean
- perimeter_mean
- area_mean
- concavity_mean
- symmetry_mean

### Cervical Cancer (5 fields)
- age (integer)
- hpv (0/1)
- smoking (0/1)
- pregnancies (integer)
- std_history (0/1)
